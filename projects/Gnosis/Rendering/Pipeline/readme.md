# 🔄 Pipeline 渲染管线模块

## 📋 概述

Pipeline 模块提供可配置的渲染管线架构，支持帧图（Frame Graph）调度和渲染通道管理。

## 🎯 核心职责

| 职责 | 描述 |
|:---|:---|
| 帧图调度 | 自动管理渲染通道依赖和资源 |
| 渲染通道 | 定义单个渲染操作 |
| 管线配置 | 配置渲染管线阶段 |

## 🏗️ 组件结构

```
Pipeline/
├── IFrameGraph.cs       # 帧图接口
├── IRenderPass.cs       # 渲染通道接口
├── IRenderPipeline.cs   # 渲染管线接口
├── RenderContext.cs     # 渲染上下文
└── ResourceDesc.cs      # 资源描述
```
