# Gnosis 引擎

## 项目名称

Gnosis 引擎

## 描述

采用多阶段编程（MSP）范式的跨平台游戏引擎。

## 核心特性

- **gg 语言编译器** - 支持多阶段编程的游戏专用语言编译器
- **字节码虚拟机** - 高性能字节码执行引擎，支持热重载
- **ECS 运行时** - 实体组件系统架构，优化游戏逻辑组织
- **渲染抽象层** - 可插拔的渲染后端（OpenGL、Vulkan、DirectX、Metal）
- **网络同步** - 客户端-服务器架构，支持状态同步和帧同步
- **反作弊防御** - 多层次反作弊系统，保护游戏公平性

## 架构概览

```
Gnosis/
├── Core/           # 核心抽象和基础类型
├── Compiler/       # gg 语言编译器
├── VM/             # 字节码虚拟机
├── ECS/            # 实体组件系统
├── Rendering/      # 渲染抽象层
├── Network/        # 网络同步模块
├── AntiCheat/      # 反作弊系统
└── Infrastructure/ # 基础设施实现
```
