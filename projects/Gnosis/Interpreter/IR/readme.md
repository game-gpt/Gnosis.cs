# 📝 IR 中间表示模块

## 📋 概述

IR 模块定义字节码的中间表示，是编译器后端和虚拟机之间的桥梁。

## 🎯 核心职责

| 职责 | 描述 |
|:---|:---|
| 操作码定义 | 定义虚拟机支持的所有操作码 |
| IR 结构 | 定义字节码的中间表示结构 |

## 🏗️ 组件结构

```
IR/
├── OpCode.cs        # 操作码枚举
└── BytecodeIR.cs    # 字节码 IR 定义
```

## 🔗 相关模块

- [VM](../VM) - 执行字节码
- [Compiler/Backend](../../Compiler/Backend) - 生成字节码
