# 🎮 VM 虚拟机模块

## 📋 概述

VM 模块是 gg 虚拟机的核心实现，负责执行字节码、管理内存、支持热重载。

## 🎯 核心职责

| 职责 | 描述 |
|:---|:---|
| 字节码解释 | 解释执行字节码指令 |
| 栈管理 | 管理操作数栈和调用栈 |
| 内存管理 | 分配和回收虚拟机内存 |
| 模块加载 | 动态加载字节码模块 |
| 热重载 | 运行时替换模块代码 |
| 原生调用 | 调用 C# 原生函数 |

## 🏗️ 组件结构

```
VM/
├── VMInterpreter.cs         # 虚拟机解释器主类
├── VMState.cs               # 虚拟机运行状态
├── VMStack.cs               # 虚拟机栈
├── MemoryManager.cs         # 内存管理器
├── NativeFunctionRegistry.cs # 原生函数注册表
├── BytecodeModuleAdapter.cs # 模块适配器
├── IModuleReloader.cs       # 模块热重载接口
└── VMExceptions.cs          # 虚拟机异常定义
```
