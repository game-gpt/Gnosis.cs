# 🎨 Widget 编辑器组件模块

## 📋 概述

Widget 模块提供编辑器 UI 组件，采用声明式设计，支持快速构建编辑器界面。

## 🎯 核心组件

| 组件 | 描述 |
|:---|:---|
| `ButtonWidget` | 按钮组件 |
| `TextWidget` | 文本组件 |
| `RectWidget` | 矩形组件 |
| `ContainerWidget` | 容器组件 |
| `HBox` / `VBox` | 水平/垂直布局 |
| `Stack` | 堆叠布局 |
| `SeparatorWidget` | 分隔符 |
| `SizedBox` | 固定尺寸盒子 |

## 🏗️ 布局系统

```
┌─────────────────────────────────┐
│           Container              │
│  ┌─────────┐ ┌───────────────┐  │
│  │  HBox   │ │     VBox      │  │
│  │ ┌───┬───┤ │ ┌───────────┐ │  │
│  │ │ A │ B │ │ │    Text   │ │  │
│  │ └───┴───┘ │ ├───────────┤ │  │
│  │           │ │  Button   │ │  │
│  │           │ └───────────┘ │  │
│  └─────────┘ └───────────────┘  │
└─────────────────────────────────┘
```
